# Facebook Clone Website

This project is a Facebook-inspired website clone that I built while following a Git and GitHub tutorial. The main goal of this project was not only to recreate the look and feel of Facebook's user interface but also to gain practical experience with version control, repository management, commits, branches, and collaboration workflows using Git.

## Project Overview

The Facebook Clone Website is a front-end web project designed to replicate some of the core visual elements of Facebook, including:

- Navigation bar
- User profile section
- News feed layout
- Post cards
- Sidebar navigation
- Responsive design elements

This project helped me understand how real-world websites are structured and how developers manage project files using Git.
